Daftar transaksi

Tambah, edit, konfirmasi, atau hapus transaksi tersimpan di perangkat.

Catatan akuntansi: nilai “Penjualan” adalah omzet, bukan otomatis laba. Laba bersih hanya final jika kg terjual dan DO terkait sudah dicatat, serta biaya operasional sudah lengkap.

DO & stok ayam

Perhitungan stok memakai transaksi terverifikasi saja.

Rincian per DO

Stok tersisa = kg pembelian terverifikasi − kg penjualan terverifikasi yang ditautkan ke DO.

Penting: jika penjualan tidak diisi dalam kg atau tidak ditautkan ke DO, stok dan harga pokok untuk penjualan itu belum bisa dihitung dengan benar. Penjualan tersebut akan ditandai di kualitas pencatatan.

Laporan pembukuan

Angka dihitung otomatis dari transaksi yang sudah dikonfirmasi.

ℹ️
Laba bersih belum dapat dipastikan

Lengkapi kg terjual dan tautan DO untuk menghitung harga pokok penjualan. Catatan yang belum diverifikasi tidak dipakai di laporan.

Cadangkan & pulihkan

Simpan salinan data agar tidak hilang saat perangkat diganti.

🔐
Penyimpanan lokal

Data berada di penyimpanan aplikasi/peramban pada perangkat ini. Tidak ada sinkronisasi cloud otomatis. Simpan file cadangan secara berkala dan jangan menghapus data aplikasi sebelum mencadangkannya.

📦

Ekspor cadangan penuh

File JSON berisi seluruh transaksi, termasuk draf yang belum diverifikasi, catatan, dan statusnya. Gunakan untuk pindah perangkat atau memulihkan data.

📄

Ekspor transaksi CSV

File CSV bisa dibuka di Excel atau Google Sheets. Ekspor menyertakan status draf agar data yang belum valid tidak tersamarkan.

↩️

Pulihkan dari JSON

Memuat data dari file cadangan AyamKas Pro. Data aplikasi sekarang akan diganti setelah Anda menyetujui pemulihan.

🧹

Reset data perangkat

Menghapus seluruh transaksi tersimpan di aplikasi ini. Tindakan ini tidak bisa dibatalkan kecuali Anda punya cadangan JSON.
